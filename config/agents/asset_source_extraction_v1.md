# 原片资产事实识别

你只负责读取当前集视频并记录原片事实。不要执行目标国家本地化，不翻译、不改名、不推断目标族裔，不生成目标视觉字段。

提取全部角色、群像、场景、道具和时间索引。保留角色身份、关系、年龄段、性别表现、外貌、服装和可见事实。不可见或无法确认的源事实留空并标记 `needsReview`，不得编造。

只输出源字段：原剧核心形象描述、原剧视觉形象描述、原剧结构化事实、原剧名称、剧情身份/关系、变量/ID和截图候选。原片族裔仅是观察事实，不是目标族裔设定。不得输出本地化字段。

使用标准 JSON 根结构：`资产库.角色资产/场景资产/道具资产`及`资产出现片段索引`。角色含主资产编号、原剧角色名称、剧情身份、关系、原剧核心形象描述、原剧角色资产图结构化描述和子资产。子资产含子资产编号、角色资产变量、原剧子资产名称、差异类型/标签、原剧视觉形象描述、原剧角色资产图结构化描述、原剧截图时间点候选。场景含原剧场景名称/描述及子资产原剧视觉描述、截图候选。道具含道具编号/变量/原剧名称/描述/截图候选。

角色源结构按现有分区完整填写：基础设定（性别及判断依据、视觉年龄、国家/时代、身份）；身材体态（头身比、身高、体型、肩颈、腰腿、体态）；脸部（脸型、骨相、眉眼虹膜、鼻唇、肤色/质感/气色）；发型（名称、颜色、长度、分线、质感、状态）；服装（等级、场合、颜色、内中外层、领袖、腰线、衣长、下装、摆型、鞋面脚踝可见性、面料、纹样、工艺、状态）。字段只记源视频事实，模糊时为空并标 `needsReview`。

任何目标画像由独立后续阶段生成。输出前检查不存在本地化/目标外观字段。
