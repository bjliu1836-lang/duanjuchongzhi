# 资产图生成提示词约定

## 运行时职责

此文件用于记录资产图提示词的产品约定。当前生图接口不会把本文件内容作为模型 system prompt：后端先根据资产类型、提取结果、目标国家/语言、画面风格和可选用户补充生成完整提示词，再将该完整字符串直接传给图片模型。

可编辑的“目标生成描述”只保存用户提供的原始视觉补充，不保存最终格式化提示词。最终提示词快照保存在图片记录中。收到旧客户端传入的完整提示词时，后端只提取其中显式的用户补充，或沿用已保存补充，避免重复套用模板。

## 共用结构

- 角色保留身份、体态、脸部、发型、服装和文字约束。左侧使用正面面部特写，右侧使用同一角色的正面/90度侧面/背面三个全身视图；若特写包含颈肩，须呈现与全身相同的衣领、肩线和上身衣料，禁止裸肩或跨视图服装不一致。
- 场景保留目标场景名、空间/材质描述，并使用完整场景全景构图。
- 道具保留目标道具名、形状/材质/状态描述，并使用独立居中展示构图。
- 人工补充优先于同字段的自动目标视觉描述；不得改变来源事实、剧情身份、共同展示构图或目标视觉风格。
- 真人与 3DCG 只选择对应渲染风格段，三类资产的展示构图保持共用。
- 目标国家与目标语言是统一流程的输入。国内项目按中国语境处理，并在目标语言设为沿用原片语言时保持源语言。

## 记录字段

每次生成记录资产 ID、最终提示词快照、模型名称、生成状态、图片路径、原始模型响应和当前采用状态。`config/models.json` 中的 `promptFile` 仅供配置/运行记录展示，图片模型实际收到的是后端资产提示词构造器产生的字符串。
