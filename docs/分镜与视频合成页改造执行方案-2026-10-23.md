## 1. 背景与目标

当前分镜页把资产引用、提示词编辑、模拟任务和分镜卡片放在三栏加底栏布局里；中央顶部又出现“分镜画面类型 真人/CG”选择。用户指出类型前置已选，这里重复显得突兀。视频页只列 mock 任务，没有真实预览、时间线或导出。

本次目标是把分镜页组织成深色紧凑的资产/原分镜编辑工作台，把视频页独立组织成真实的素材编排和合成工作区。参考图提供结构与交互方向，不能把图中的控件视为本项目已经具备的能力。视觉改造仅落在这两个页面。

## 2. 现状与证据

- 分镜工作台位于 frontend/src/App.tsx 的 #segments，含资产栏、中央分镜编辑区、右侧任务/预览、底部分镜横条。基础网格在 src/styles.css：原列约 370px / 主区 / 430px，底部 210px；frontend/src/styles.css 有后续覆盖。实施前需核对 import/cascade，避免旧规则叠加。
- 后端创建/派生项目与更新接口已有 storyboardVisualStyle 字段，持久化在 projects.storyboard_visual_style；服务端分镜模板根据项目字段路由。当前分镜顶部 selector 是唯一明显的真人/CG选择入口。
- **当前前置 UI 尚无真正的真人/CG选择**：创建/上传确认 payload 已传 storyboardVisualStyle，但可见的“风格”仅海外模式“写实通用/欧美短剧/广告质感”，它不是画面类型；替换模式没有真人/CG控件，React 临时 state 默认 live_action。故实施顺序必须是先在前置配置补真人/3DCG选择并绑定同一字段，确认创建、更新、派生均回读此字段，再移除分镜 selector。3DCG模式锁定CG；海外目标风格继续独立存在。
- 后端 storyboards 表每行保存 episode_id/title/time_range/prompt/payload_json/status。实查项目 project_584d3afef523 的样例 payload 有来源片段编号、单一分镜时间范围、引用资产、源文本和提示词快照，没有嵌套的多条细分镜清单。当前无独立片段表。每条 storyboard 行是当前可编辑的分镜生成单元；正文可能含自由文本中的多镜头描述，但不代表系统已有可独立编辑的细分镜实体。底部每张卡映射一条 storyboard 生成单元，不推断为参考图里的源片“片段06”，也不新增模型或重解析算法。正文照原文展示；结构字段存在时才分项展示。
- 分镜 API 已有列表/创建/更新/删除/移动；前端已有编辑保存、复制、排序、删除、引用、重新生成等现存动作。
- video_generations 当前将 Mock video generation placeholder 写入 .txt，payload.mock=true；不存在真实 MP4 输出。记录保留在任务历史，但必须被合成素材库过滤。
- data/projects 下已有真实本地 MP4；后端 /api/files/{path} 通过受控 DATA_DIR 路径返回 FileResponse，可供本地源片播放。浏览器兼容性仍需对具体文件验证。
- 当前 Windows 环境可找到 FFmpeg 8.0.1，后端也通过 shutil.which 与子进程调用 FFmpeg 抽取关键帧；backend/requirements.txt 不含视频编辑库。环境有 ffmpeg 不代表部署机已安装，也不代表已有后台导出 job、进度/取消/恢复机制或输出校验。

## 3. 本次变更范围

### 3.1 真人/3DCG唯一来源

- 在首页制作模式设置/上传前置参数中增加“分镜画面：真人 / 3DCG”。海外本土化、替换模式可选；3DCG模式固定为3DCG。替换模式新项目默认真人，但已有项目必须回显 API 字段，不能用默认 state 覆盖。
- 创建、更新模式、另存派生和上传确认都沿用 projects.storyboard_visual_style / 请求 storyboardVisualStyle。保存后以 API 返回的 project 值更新前端状态。确认页若展示类型则只读。
- 删除分镜页面内 selector；不改变服务端模板、源拆解或语言路由。选择变化沿用既有“待更新”标记，不重跑源分析、不自动发起生成。
- “写实通用/欧美短剧/广告质感”仍作为海外目标风格，不可与真人/CG字段混用。

### 3.2 分镜工作台布局

以 1440×900 桌面窗口为验收基准，使用深色紧凑工作区，仅作用于分镜和合成页。

| 模块 | 建议尺寸/位置 | 交互与边界 |
|---|---|---|
| 顶栏 | 全宽高44–52px | 项目、集、保存状态、页面导航紧凑排列；类型仅低调只读信息或不显示，不再作为显眼同级模块。保存状态依真实 API。 |
| 左资产库 | 固定240–280px，贯穿主区和底栏 | 搜索、集选择、分组折叠、列表/网格切换、角色/场景/道具缩略图；按已有资产映射显示当前引用，可搜索/切换本集资产。点击引用必须写入现有分镜数据。无图明确显示空态。 |
| 中央正文 | 弹性宽度，建议占剩余宽度60–68%，独立纵向滚动 | 显示当前分镜标题和时间范围、原分镜正文、现有资产 chips、现有提示词编辑/保存及引用动作。自由文本原样展示；仅当 payload 已明确提供机位/背景/站位/动作/对白/时长字段时分项呈现，不拆句、不重解析。 |
| 右侧预览 | 300–360px，9:16内容contain | 原片从当前集受控资源播放，并按有效 time_range 定位；生成结果/对比仅当存在真实可播视频时开放。mock 记录不能播放或加入对比。无素材显示状态，不放白模占位。 |
| 底部胶片条 | 主区下方高150–190px，中央与右侧横跨，左栏保持全高 | 只按真实数据实体命名。每卡映射一条 storyboard 分镜生成单元，显示标题/时间码/选中态/真实已有缩略图；正文自由文本里的多镜头描述仍在正文整体展示，不拆成卡片。不得称作源片片段实体。若无缩略图，仅显示文字和时间码，不伪造帧。保留已有 CRUD 与排序。 |

≤1100px 时，资产库折叠成可开关抽屉，右预览可折叠，正文先占满；胶片条保持独立横向滚动。焦点、禁用、加载和选中状态必须可见。

### 3.3 视频合成页可确认 MVP

独立视频工作区建议本期形成真实闭环：真实素材导入/引用 → 单视频轨排序与裁切 → 真实顺序预览 → SQLite草稿保存 → FFmpeg后台导出MP4并下载。AI视频生成模型接入不是前提。

- 顶栏：项目/集/草稿名、真实保存状态、画幅、收起面板、导出。画幅/分辨率不能继承资产角色模板的8K文字；使用项目真实配置，缺失时提供本合成草稿的清楚默认值。
- 左侧资源栏宽250–290px：搜索、当前集本地原片、用户导入视频、真实可播放的生成文件；显示时长、缩略图、来源和是否已加入。原片只作为参考资源展示，只有用户明确点击“加入时间线”或导入后才进入合成，不得自动以原片补缺失的分镜生成视频。生成结果仅在对应storyboard确有真实MP4文件时可加入。上传后落盘到项目目录，刷新后仍可访问；浏览器临时blob URL不作为持久数据。
- 中部画布：按项目比例 contain，9:16时黑色留边；播放/暂停、播放时间、seek、音量。当前原片或导入素材无法播放时，给出真实失败原因和重新选择入口。
- 右侧检查器宽280–320px：选中 clip 后显示源素材、入点、出点、有效时长及顺序；裁切值限定在实际素材时长内。未选中时显示轻量空态。
- 下方时间线高230–300px，可折叠；播放控制、刻度、游标、仅一条视频轨。clip 依顺序连续排列，宽度按有效时长反映；支持拖动和上移/下移替代排序、单个 clip 裁切、移除、替换。
- 空轨只显示“添加本地视频/从本集添加”。当前不提供字幕、音频/配乐、转场、白模、3D导演台、多轨按钮或装饰性假轨。
- 建议首版一个 episode 一个合成草稿。是否需要多个命名版本作为待确认项。

## 4. 数据与 API 草案

现有 storyboards/video_generations 不承载剪辑状态。新增独立合成草稿和导出任务，避免把剪辑参数塞进提示词或 mock 任务。实施前按当前 SQLite 迁移及 ID 风格核对。

剪辑草稿 JSON示例：

    {
      "projectId": "project_x",
      "episodeId": "episode_x",
      "title": "第1集合成",
      "aspectRatio": "9:16",
      "revision": 4,
      "clips": [
        {
          "id": "clip_x",
          "sourceId": "video_asset_x",
          "sourceKind": "episode_video",
          "sourceDurationMs": 52000,
          "inMs": 0,
          "outMs": 6800,
          "order": 0
        }
      ],
      "updatedAt": "..."
    }

客户端只传资源ID、时间点和顺序，不提交任意文件路径。服务端解析资源归属和真实路径。

| API草案 | 职责 |
|---|---|
| GET /api/projects/{project_id}/episodes/{episode_id}/video-assets | 返回本集可用原片、用户导入文件和确有输出文件的生成视频；排除 mock 文本。 |
| POST /api/projects/{project_id}/video-assets | 上传文件、校验、落盘并保存metadata，返回受控播放URL、时长、尺寸、音视频流信息。 |
| GET /api/projects/{project_id}/video-edits/{episode_id} | 读取剪辑草稿；无草稿返回明确空状态和默认画幅。 |
| PUT /api/projects/{project_id}/video-edits/{episode_id} | 校验片段资源、顺序、裁切范围后整体保存，revision防并发覆盖。 |
| POST /api/projects/{project_id}/video-edits/{episode_id}/exports | 建立后台导出任务并立即返回jobId。 |
| GET /api/projects/{project_id}/video-export-jobs/{job_id} | 返回真实任务状态、进度阶段、错误和成功后的下载资源URL。 |

导出任务至少保存 project/episode/edit revision、参数快照、queued/running/succeeded/failed/cancelled状态、真实进度、输入输出路径、错误、创建/结束时间。

## 5. 导出规格与失败处理

- 使用无 shell 拼接的固定 FFmpeg 参数；验证所有资源归属当前项目、路径在受控目录、文件可读，clip 入出点合法，输出目录属项目。
- 顺序导出采用逐段解码/统一参数再 concat，统一画幅、分辨率、帧率、像素格式与音频采样参数。输出比例不同用等比缩放加 pad 保留主体，不静默裁切。
- 有音轨的视频保留音轨并统一编码；无音轨片段按固定策略补静音以保持流结构一致，且不能造成片段时长偏移。导出前后验证流结构，避免时长/音频错位。
- 默认画幅跟随合成项目设置；若输入素材比例不同，letterbox/pad。分辨率默认取项目输出设置；若当前没有持久化输出分辨率，则本剪辑草稿保存一个明确默认值，并在顶栏可见。不得使用角色模板中的“8K”文本做输出规格。
- 使用 FFmpeg -progress 输出的 out_time_ms 对照预计时长计算进度。无法读取进度时显示阶段状态，不编造百分比。长任务在后台执行，刷新后可恢复状态；导出成功需用 ffprobe/FFmpeg 检查输出确有视频流且可读。
- FFmpeg 缺失、文件损坏、编码不支持、磁盘不足、参数越界或任务中断时标失败/中断并说明原因，保留草稿、不出现下载按钮。真实本地可播生成文件可作为普通素材；mock 生成记录和 .txt 永不进入素材库。导出只包含用户明确加入时间线的素材与选定区间，名称和状态标注“所选片段合成”，不宣称整集完成。当前数据不能自动判定整集分镜覆盖率；如需整集完整性提示，需先定义预期生成单元及缺项规则。

## 6. 不变范围

不改分镜反向拆解/切分算法、Agent prompt、模式语言路由、项目派生隔离、资产替换和源/目标数据边界；不覆盖源文本、时间码、资产引用。当前没有结构化细分镜时只展示源叙述。AI视频生成仍为 mock，不把其接入算本期要求。全站样式与首页、资产页不在范围；不恢复A/B/C方案。

## 8. 数据状态与异常

| 对象 | 校验 | 失败表现 |
|---|---|---|
| 剪辑草稿 | clips引用同项目可用资源；inMs≥0、outMs>inMs、outMs≤源时长；revision一致 | 保存失败保留本地编辑，不静默覆盖；冲突提示重载或恢复服务器版本 |
| 视频素材 | available/missing/unsupported；服务端受控路径 | 缺失/不支持不可加轨；提示重新上传/换素材 |
| 导出任务 | queued/running/succeeded/failed/cancelled；成功需有真实输出且通过媒体检查 | 失败保留草稿、不显示下载；暴露可读错误 |
| 分镜数据 | 按payload现有结构展示；time_range解析成功才能seek | 自由文本照常显示；坏时间码显示无法定位，不推算新时间 |

存量 storyboards 和 video_generations 不迁移；mock历史照常可见但不进入素材库。clip 用独立 ID 与视频资源 ID，不以 storyboard 行作为默认视频素材。合法项目画面类型回显原值；缺值兼容真人，保存后写回；海外目标风格不推断成CG。

## 9. 分期与非目标

推荐本期：类型入口归一、分镜页重排、视频合成最小真实闭环（真实素材→单视频轨→裁切/排序→草稿保存→原生预览→异步导出）。

完整参考图3的字幕/多轨音频/配乐、转场、复杂关键帧、白模、3D导演台属于后续评估。它们依赖音画同步、混音、字幕数据格式、叠轨/冲突、撤销历史和导出参数等独立产品规则；本期若未实现就不展示入口。AI视频模型接入单独进行，不是合成页前提。若本期必须包含完整多轨，需先评审轨道种类、音频交叠/混音、字幕时间轴、撤销重做和导出规则，再扩充范围。

## 10. 待用户确认项

1. 是否接受“单视频轨真实导入、排序、裁切、移除/替换、保存、预览、FFmpeg导出”的本期闭环，字幕/音轨/转场/白模/复杂多轨后续再评估？
