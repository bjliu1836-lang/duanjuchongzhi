## 1. 结论

建议把“重制模式”作为项目级配置，和目标国家、语言分开；另设独立的项目级 `storyboardVisualStyle`（`live_action` / `cg_3d`），控制最终分镜生成描述的画面类型，不参与源分镜拆解。海外模式默认真人，3DCG模式固定3DCG，替换模式由用户明确选择真人或3DCG，不能根据上传图片自动猜测。三种模式共用原片分析、原资产身份、出现片段索引和分镜时间/演绎；每个项目只保留一个当前重制模式。已有目标图后如要切换重制模式，通过“另存为新制作项目”保留原项目，派生项目复用原视频与解析数据。切换分镜画面类型只影响最终生成描述，不重跑源拆解、不覆盖旧结果，并将受影响的下游结果标为待更新，不自动执行付费生成。

这次先验证可控资产图效果：同一集挑少量角色与场景生成/上传样例，按资产一致性、原视频轮廓保留、风格符合度和人工返工率评估。不要把可用的单张资产图效果外推成整片效果。当前视频生成接口仍为 mock；本方案不把“接通真实视频生成”纳入本期交付。

## 2. 产品判断

需求来自短剧重制生产者，产品应优先让制作用户快速对比目标版本，并确保下游引用关系稳定。复用解析数据能减少重复分析；分离“原剧事实”和“项目当前模式处理规则”能避免制作人员修订模式时损坏源资料。主要成本在资产一致性和模型生成结果不稳定，故一期应把样例资产验证作为上线前门槛。

| 判断项 | 结论 |
|---|---|
| 是否值得做 | 值得验证。它在海外本土化以外新增3DCG表达和低改动资产替换，能拓宽重制产物类型。 |
| MVP 是否过重 | 若同时建设多人协作、3D模型导出、导演台、全片视频复现和审片工作流会过重；本期只做项目模式选择、提示词分层、资产图生成/上传/采用，以及已有目标图后切换模式时另存派生项目。 |
| 是否必须用 AI | AI适合从原视频提取资产事实、生成描述和资产图；来源描述、模式类型、固定约束、资产映射和状态流转应由系统规则管理。人工上传是必要的非AI路径。 |
| 主要风险 | 原始描述被本地化覆盖；国内版本误带英语或海外视觉；某个角色/场景版本未映射导致混用；手动上传图与资产类型不符；样例资产成功但镜头视频生成失败。 |
| 推荐路径 | 先以同片少量角色/场景验证3DCG资产图和资产替换资产图；样例通过后再进入项目批量生成。后续真实视频能力可用时另取3–5个代表镜头验证，再决定全片范围。 |

## 4. 产品范围与项目模式策略

### 一期增加

1. **项目级单一模式**：每个项目选择“海外本土化”“3DCG风格”“替换角色/场景形象”之一。目标国家/目标语言独立于模式；国内模式默认保留原片语言，不走海外化/翻译。替换模式有角色、场景两个默认关闭的开关，可仅换角色、仅换场景、两者都换或都不换。
2. **复用解析**：切换模式不重跑原片分析，不改源资产身份、出现时间索引和分镜源数据。项目模式只控制资产目标描述、目标图来源/采用关系和最终提示词组装。
3. **已有产出后的切换**：项目已有任何目标资产图后切换模式，提示用户“另存为新制作项目”。派生项目复制/引用原视频、原片分析与分镜源数据，保留稳定的源资产键；不复制不适配新模式的目标资产描述、生成图和采用图。原项目完整保留。新项目按所选模式重新生成/上传目标资产。项目管理列表可显示“基于项目X另存”，直接打开原项目即可查看旧结果，不增加项目内版本历史、恢复或比较系统。
4. **资产与分镜提示词分层**：原剧资产描述只读溯源；当前项目模式的目标资产生成描述/用户提示词可编辑；角色资产固定模板、场景资产固定模板分别作用于对应资产；最终资产生图提示词只读预览并保存快照。分镜最终生成描述由未覆盖的源分镜结构/表演描述、当前项目已确认目标资产引用和独立“分镜画面约束”组成，画面类型单独配置并保存模板版本快照。
5. **替换资产来源**：被选中的角色/场景可手动填写提示词生成图，也可上传本地资产图。未选资产沿用原貌/原图，不强迫生成。
6. **确认与引用**：新目标图确认后成为该派生项目该资产的权威图。原描述只用于源片溯源，不再当目标外观约束。稳定源资产键用于把新目标角色映射到原分镜动作；@引用、目标显示名称/描述和真实视频生成的资产图输入必须解析到当前项目的已确认目标资产。国内模式禁止旧海外化名称/描述覆盖目标图。

### 明确不变

- 不改原片上传、源解析和分镜反向拆解规则，不重建镜头时间、动作、镜头语言和资产出现索引。分镜画面类型只改变最终生成描述的独立约束层，不覆盖源拆解文本。
- 不把3DCG/替换描述写回原剧源描述，不改变源角色键与时间/动作映射。
- 不自动更改目标国家/语言；国内模式用原片语言，海外本土化继续沿用项目目标国家/语言。
- 不建设项目内多版本历史/恢复界面，不建设白模、可编辑3D网格/骨骼、导演台、真实视频生成和全片导出。

### 产品理性评审

完整 rendition 系统会增加并行版本权限、跨版本引用和历史管理，一期没有必要。更轻的方案是每项目单一模式：还没有目标图时原项目直接切换；已经生成目标图时另存派生项目，并只复制可复用的源数据，不带入不兼容目标资产。这样保留旧结果，也不增加项目内版本管理UI。派生项目复制源分析数据有工程成本，但比重新分析省时，且边界清晰；实施前需确认删除/存储策略能安全共享或复制视频和源帧文件。

### 5.1 首页上传/项目设置

在现有目标国家与生成参数旁新增“制作模式”：海外本土化、3DCG风格、替换角色/场景。默认保留既有海外模式，避免旧用户路径变化。目标国家/语言只在海外模式启用；国内模式使用源语言（语言未识别时由用户选择）。替换模式展示`替换角色形象`、`替换场景形象`两个默认关闭的独立开关。

切模式的规则清晰区分：尚无目标资产图时在当前项目直接改项目配置；已有目标资产图时弹窗“另存为新制作项目”。确认后新建派生项目，复用视频、源分析、源资产键和分镜源数据，清空/不复制目标生成描述、目标图和旧模式采用状态。项目列表显示派生关系；用户回原项目即可查看原模式结果。不加项目内的版本历史下拉或恢复入口。

### 5.2 设定页概览

保留角色/场景/道具和原有资产组，显示当前项目模式与该项目目标资产状态。替换模式中，未选择的类型显示“沿用原貌”；已选择的类型显示“待生成/待上传/待确认/已采用”。批量生成只处理用户选中的替换资产。项目卡片而非资产页负责说明派生来源。

### 5.3 资产详情

左侧保留原片帧、原始描述、出现集数/时间码、角色关系或场景功能；右侧用四层呈现生成逻辑：

| 层 | 字段与规则 |
|---|---|
| 1. 源片事实 | 原剧资产描述/原图，只读且只用于追溯、对照。替换模式下不将源描述年龄、性别、物种、脸型或真人质感继续作为目标外观约束；原资产即使是中年真人男性，也可替换成动物、卡通或全新人设。 |
| 2. 目标生成描述 | 当前项目模式下可编辑。3DCG初始值从源资料结构化映射，保留原剧身份、年龄、发型服装、道具、时代和建筑布局；替换模式允许完全不同的人物/动物/卡通/全新人设，用户描述和确认图决定目标外观。 |
| 3. 固定风格约束 | 系统维护、默认锁定。3DCG角色资产使用本方案列出的角色固定模板；场景使用独立场景模板（已随执行授权确认），不可把角色四视图模板套到场景；道具如当前链路依赖，沿用现有原资产流程，不扩展风格模板库。源描述原文只读留存；如含摄影、白底、多视图等冲突要求，只在单独的可编辑目标生成描述中清理，不能改写源描述或固定模板。角色资产表的白底、多视图、胸像/全身姿势只用于角色生图，不加入分镜画面提示词。海外版沿用现有逻辑；替换版沿用现有原资产目标流程。 |
| 4. 最终提示词预览 | 只读，展示实际传给生图模型的合成内容。每个候选图沿用现有单资产历史记录保存完整提示词快照。 |

按钮：`编辑目标描述`、`生成候选图`、`上传资产图`、`设为当前采用图`、`重新生成`、`恢复沿用原图`。上传图必须保存到项目本地持久文件，记录MIME类型/路径、上传来源、当前项目资产键和采用状态，不能只存临时URL。稳定源资产键用于镜头动作映射；派生项目中的数据库行ID可变化，目标显示名和图单独保存。确认目标图后，分镜资产解析要指向确认图，不能再将旧海外名称/描述当目标外观事实。

### 5.4 分镜页

保留原分镜顺序、时间码、动作、情绪、站位、构图、景别、运镜和时长信息；项目重制模式控制资产目标外观和内容本地化参数，独立的 `storyboardVisualStyle` 控制最终分镜画面类型。海外模式沿用现有本地化且默认真人；3DCG模式固定CG；替换模式要求用户明确选择真人或3DCG。国内3DCG/替换模式使用源语言，不注入目标国家翻译。源资产键用于关联“谁在何时做原动作”，目标图和目标显示名取当前项目已确认映射。若真实视频接口未开启，只验收描述和引用数据，不把mock成片当作成功。

## 7. 状态、异常与回归边界


- 项目模式状态：`待配置 → 资产待生成/待上传 → 待确认 → 可进入分镜`。沿用原貌资产视为已满足，不阻塞进入分镜。已有目标图后切模式必须另存派生项目；原项目不变，新项目只含复用的源分析数据。
- 生成失败、上传格式/大小校验失败、类型不匹配、缺少当前版本采用图：只影响当前项目资产，保留上一采用图并提示；不破坏源资产或原项目。
- 重新解析仍可能覆盖同集资产记录（当前后端会删除并重建该集资产）；另存派生项目应复制解析数据而不是重跑此流程。原项目留档可以避免新模式操作覆盖旧目标图。
- 需回归：旧海外项目显示/重新生成不变且缺省分镜画面类型为真人；已有目标图后另存派生项目并保留原项目；派生项目不复制不匹配的目标资产；仅换角色、仅换场景、两者都换和均不换；3DCG分镜最终描述含CG约束且不含真人摄影冲突约束；海外默认真人、3DCG固定CG、替换模式由用户明确选择真人/CG，上传图片类型不触发自动猜测；国内版本不自动翻译或海外本土化；切换资产子状态后引用正确图；重生成失败保持原采用图；本地上传图能显示、设为采用并写入历史；原片时间索引与分镜源描述不被模式或资产操作改写；切换分镜画面类型不重跑拆解、不覆盖旧结果、不自动触发付费生成。

## 8. 验收指标与建议门槛


资产样例评估由制作人员盲评：

- 源事实保留：身份、年龄段、关键服装/道具/建筑布局与源描述相符；被修改字段均能定位到版本描述。
- 风格符合度：角色按已确认角色固定模板验收；场景按另行确认的场景模板验收，不用同一四视图模板覆盖两类资产。最终角色生图请求不得混入未清理的照片级真人冲突词；分镜提示词不得含角色资产表的白底、多视图、胸像或站姿布局约束。
- 资产映射：选中的角色/场景版本能被分镜引用；未选对象沿用原图，不能因缺新图阻塞。
- 项目留存：派生项目的资产生成/上传不影响原项目的目标图和提示词；回到原项目可继续查看旧结果。
- 国内内容：3DCG/替换版本在分镜输入中使用原语言，不注入目标国家翻译；对于当前 Agent 无法保证的内容标为未验收，不用静态UI或mock结果代替。
- 分镜画面类型：对同源镜头分别生成真人与3DCG最终描述时，源内容结构字段保持不变；对应画面约束不同且只追加一次。替换模式必须由人工明确选择类型；服务端预览/生成/批量/重试结果一致，模板版本和最终提示词快照可追溯；角色/场景资产表布局词不进入分镜提示词。切换类型只标记下游待更新，不自动生成；已有项目缺省真人保持兼容。该验收仅覆盖描述和引用链路，不代表真实成片生成。
- 视频成片质量另设阶段门槛：只有真实视频生成链路启用后，才以3–5个代表镜头检查动作/站位/运镜保留度和资产连续性；当前 mock 不计成片通过。
