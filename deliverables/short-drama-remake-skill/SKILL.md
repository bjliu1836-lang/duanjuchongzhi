# 短剧重制拆解 Skill

把一集剧集视频转化为"结构化资产库 + 逐分镜视频生成提示词"的三阶段提示词包。

## 包内容

```
prompts/
  asset_source_extraction.md        # 阶段1：原片资产事实识别（读视频 → 源事实快照）
  asset_target_localization.md      # 阶段2：目标资产本地化（源快照 → 目标文化画像 patch）
  storyboard_prompt_generation.md   # 阶段3：分镜拆解与视频生成提示词（视频+资产 → 分镜JSON）
```

## 执行顺序与数据流

```
当前集视频
   │  阶段1 资产源提取（需要视频理解能力）
   ▼
源事实快照：资产库（角色/场景/道具 + 子资产 + 稳定变量）+ 资产出现片段索引
   │  阶段2 目标资产本地化（纯文本，不读视频）
   ▼
目标画像：localizedProfile（patch 合并）+ 顶层 resolvedTargetEra / targetSetting（全资产共享）
   │  阶段3 分镜拆解（需要视频理解能力）
   ▼
分镜JSON：分镜列表（约10秒/个）→ 镜头列表（真实切镜）→ 最终视频生成提示词文本
```

国内项目（目标国家=中国且保留源语言）跳过阶段2，分镜阶段直接使用源资产。

## 使用方法

每个阶段独立调用一次模型：

1. **system prompt** = 对应 `prompts/` 文件的完整全文，再按项目模式追加"约束注入模板"（见下节，必须追加，否则行为不完整）。
2. **user message** = 按该阶段提示词中的"输入"模板组装，把所有 `{{占位符}}` 替换为实际值；视频类输入以模型支持的附件形式提供。
3. **输出** = 严格 JSON（阶段1/2/3 均是）。按"输出校验要点"验收，不合格应重试或拒绝，不要直接发布。

## 各阶段输入契约

### 阶段1 资产源提取
- 当前集视频（必需）
- 项目参数仅用于命名上下文，不做任何本地化
- 输出：`资产库.角色资产/场景资产/道具资产` + `资产出现片段索引`；不可确认事实填 `unknown` 并入 `needsReview`

### 阶段2 目标资产本地化
- `sourceSnapshot`：阶段1 的源事实快照（唯一事实依据，不得改写）
- `targetCountry` / `targetLanguage` / `targetEra`（`auto` 时由模型从目标国家历史选择共同时代，不默认现代化）
- `userTargetVisualSetting`（用户外观文本）、`userTargetVisualLock`（仅带明确用户来源时才构成锁定）
- `legacyPreservedDesignConstraints`（明确标为保留约束的旧设计字段，可选）
- 输出：顶层 `resolvedTargetEra` + `targetSetting` + `localizedAssets[]`（每项含 `assetVariable` 与 `localizedProfile` patch）

### 阶段3 分镜拆解
- 当前集视频（必需）、当前集编号、当前集剧本或剧情事实（可选，无则填"未提供"）
- 资产摘要：每项含 资产类型/原剧资产名称/本地化资产名称/资产变量（@短格式）/当前有效目标画像（含 目标文化背景、目标时代）
- 资产出现片段索引：阶段1 原样输出
- 目标国家、目标语言、成片画幅、目标文化背景、目标时代（后两者取自阶段2 共享背景）
- 白模参考素材：仅明确提供时填，否则填"未提供"
- 输出：分镜 JSON（结构见提示词），每个分镜含完整 `最终视频生成提示词` 文本

## 变量约定（两阶段格式不同，必须映射）

- 阶段1 输出稳定变量：角色/场景子资产 `{{CHAR_001_SUB_01}}`、`{{SCENE_001_SUB_01}}`，道具 `{{PROP_001}}`。
- 阶段3 只使用 `@资产名` 短变量（如 `@Jack-常服`）。调用方需维护"稳定变量 → @短变量"映射表并写入资产摘要；`@短变量` 建议用"本地化资产名称-子资产差异标签"生成。
- 资产出现片段索引只用于时间归属判断，不代表真实切镜，不得据此生成镜头。

## 约束注入模板（按项目模式选用）

### A. 国内模式（目标国家=中国/未指定 且 保留源语言）

在阶段3 system prompt 末尾追加：

```text
【项目模式强约束】当前是国内重制项目。不得执行目标国家替换、跨文化本土化、英文/目标语言翻译；保留源视频人物、场景、道具和文字事实，只做用户指定的视觉风格重制。成片语言保持：{源语言}。不得根据空字段猜测普通话、美国英语或其他语言，也不得将本提示当作语言识别结果。
```

### B. 海外模式（目标国家非中国 或 明确切换目标语言）

在阶段3 system prompt 末尾追加：

```text
【目标文化适配强制规则】目标时代和目标文化背景服从输入中经资产阶段确定的共同背景；如未提供有效背景，按目标国家历史与剧情关系选择，不默认当代。当前有效目标画像是资产外观唯一依据，不得另行设计族裔、服饰、场景或道具外观。保留源镜头数量、顺序、边界、景别、机位、运镜和时长；只在该框架内适配文化动作、礼俗、台词及具有相同剧情功能/价值等级/权力关系/证据识别作用的道具。找不到对应时用时代相符、文化特征较弱的通用表达，保留关系、冲突和因果，不删减。
```

### C. 分镜末尾固定拼接（所有项目）

阶段3 返回后，在每个分镜的 `最终视频生成提示词` 末尾依次拼接：

1. 项目确认资产行（该分镜引用变量逐项）：
   `当前项目确认资产：{@变量}={目标名称}；目标外观：{该资产当前有效目标画像描述或源外观描述}。…`
2. 语言路由行：海外项目写明"保持海外本土化项目的目标国家/目标语言设置"；国内项目写明"国内重制：保留源语言与源事实"。
3. 画面类型约束（按项目视觉风格二选一）：

```text
分镜画面类型约束：真人实拍电影质感。角色与环境采用真实世界的比例、材质、自然光照及摄影成像，保持原分镜的动作、情绪、站位、构图和运镜；避免三维CG与卡通渲染质感。
```

```text
分镜画面类型约束：高端三维游戏CG过场动画质感，Unreal Engine 5 cinematic render，Final Fantasy CG style，非摄影式三维网格与数字雕刻材质，PBR材质和电影级三维光照；保持原分镜的动作、情绪、站位、构图和运镜，角色与场景风格统一；避免真人摄影皮肤、照片颗粒与二维插画。
```

## 输出校验要点

### 阶段1
- JSON 合法；角色源结构所有标准键均出现；名称只写本体（不含机位/分区/颜色）；变量为稳定编号格式
- 不可见事实为 `unknown` + `needsReview`，无编造

### 阶段2
- 顶层含 `resolvedTargetEra` 与 `targetSetting`，全资产共享一致
- 角色 patch 只含允许分区：`基础设定`（族裔外貌、目标身份表达）、`脸部特征`（15 个必需字段）、`发型`（6 个必需字段）、`服装`（仅文化适配时）
- 性别/年龄层/身材/剧情关系不被 patch 覆盖；不出现自由文本外貌或 `assetImagePrompt`

### 阶段3
- 两层粒度：分镜约 8~12 秒（最长约 15 秒，一镜到底除外）；镜头为真实切镜；分镜时间范围 = 内部镜头起止
- 每镜七维字段齐全；`分镜具体动作描述` 与 `镜头描述` 留空
- 引用变量均为 @短格式、与时间范围内资产索引一致、自然嵌入画面描述
- 无后期对白字幕/平台水印；无中外语言对照；无"按原片表演"类外部指代

## 能力要求

- 阶段1/3 需要支持视频输入的多模态模型；阶段2 纯文本模型即可
- 建议对 JSON 输出做 schema 校验 + 失败自动重试一次，避免模型抖动直接抛给用户
